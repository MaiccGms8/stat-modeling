# Modelagem Estatística

Repositório destinado ao armazenamento das atividades práticas e projetos de Modelagem Estatística. 

## 📂 Estrutura do Repositório

As análises estão organizadas de forma modular, separadas pela linguagem de programação utilizada:

* **`/R_stat`**: Atividades iniciais, scripts estatísticos e relatórios dinâmicos (RMarkdown) com foco em análise exploratória, inferência e regressão usando R.
* **`/python_stat`**: Futuras implementações de modelagem e análise de dados utilizando Python.

## 🛠️ Tecnologias Principais

* **R**
* **Python**
